# BookListView
此程式為圖書清單管理，使用ListView顯示書籍資料，並提供不同檢視模式與借閱功能。
<img width="764" height="474" alt="image" src="https://github.com/user-attachments/assets/9ae42e8a-c1aa-47a4-a435-cc0cb0782a87" />

使用ListView顯示書籍資訊以及特色
1.支援多種檢視模式：
  - 大圖示
  - 詳細資料
  - 小圖示
  - 清單
  - Tile 模式

2.書籍資訊顯示：
  - 書名
  - 作者
  - 類別

3.雙擊書籍可加入借閱清單
4.防止重複借閱
